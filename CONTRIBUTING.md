# Contributing

## Development Setup

Please see [README.md](./README.md) for full setup instructions.

## Code Style

- **Backend**: ES Modules (`.js`), async/await, Zod validation on all inputs
- **Frontend**: React functional components, Next.js App Router, Tailwind CSS

## Branch Strategy

- `main` — production-ready code
- Feature branches: `feature/<name>`
- Bug fixes: `fix/<name>`

## Commit Format

```
feat: add email verification flow
fix: correct OAuth error code forwarding
chore: update dependencies
docs: add API reference to README
```
